# L2 — Auth & RBAC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the Laravel 13 backend session authentication and role-based access control — 3 roles, gates mirroring the endpoint RBAC matrix, `pdn.ac.lk` email policy, login + vault throttling, and a bootstrap admin — all proven by fresh Pest tests.

**Architecture:** Session auth on the `web` guard (cookies + CSRF; the old JWT/refresh machinery is gone). Domain logic lives in `App\Domain\Authorization\` (email policy, user directory, attempt throttle, bootstrap admin); controllers stay thin; a `role` middleware plus a test-only route group make the RBAC matrix provable before the L3–L5 domain routes exist. Roles/abilities already exist from L1 (`App\Domain\Authorization\Role` + `Ability`) and are the single source of truth.

**Tech Stack:** Laravel 13.35, PHP 8.3.6, SQLite + Eloquent, Pest 4, Laravel `RateLimiter` + session guard, Pint.

**Spec:** `docs/superpowers/specs/2026-10-09-blitto-patent-database-laravel-migration-design.md` (§6 Auth & security; §5 users table; §11 out-of-scope). Tracking issue: [#72](https://github.com/Dushmilan/BLITTO--MANAGEMENT/issues/72). Context: `BIGGER_PICTURE.md` §6/§9. Behavioral reference (never a gate): git tag `pre-laravel-final-state` — `app/modules/authorization/`, `tests/api/test_rbac_matrix.py`, `tests/edge/test_auth_edge.py`, `tests/security/test_auth_hardening.py`, `tests/conftest.py`.

## Global Constraints

- Run all commands from `backend/`. Test runner: `php artisan test --compact <args>` (or `vendor/bin/pest`).
- TDD always: RED → GREEN, one vertical slice at a time, never refactor while RED (AGENTS.md).
- Tests assert behavior through public interfaces (HTTP routes, domain class public methods) — not private internals.
- Domain logic in `app/Domain/Authorization/`; controllers thin; no business logic in controllers or Eloquent models.
- Env prefix `BLITTODB_`; session cookie/signing key is `APP_KEY` (no JWT secret exists).
- Roles are the lowercase enum values `user` / `director` / `md` (`App\Domain\Authorization\Role`).
- Status codes are part of the contract: guest `401`, wrong role `403`, non-institution email `422` on register / `403` on login, duplicate `409`, throttled `429` + `Retry-After: 600`.
- Conventional commits, prefix `feat(l2):` / `test(l2):` / `chore(l2):`.
- After code changes: `vendor/bin/pint --dirty --format agent`; at the end `graphify update .` from the repo root.
- Laravel version APIs are frozen at 13.35 — do not assume other versions.

## Review Focus

These are the input classes most likely to bite a user; the task named in parentheses owns the test that pins each one.

1. **Email case/whitespace before duplicate + login lookups.** `"  A@PDN.AC.LK "` must normalize to `a@pdn.ac.lk` and collide with the existing account, not create a second one (Task 6).
2. **Lookalike domains.** `pdn.ac.lk.evil.com` and `fakepdn.ac.lk` must be rejected; only exact-domain or dot-boundary subdomains pass (Task 2).
3. **Throttle keying.** A case-variant of a throttled email (`Victim@…` vs `victim@…`) must share the counter; distinct accounts must not (Task 9).
4. **Password edges.** A password longer than 72 bytes must be refused at registration (bcrypt truncation), and an account with no password must return `401`, never a server error (Tasks 6, 4).
5. **Unauthenticated JSON negotiation.** Every protected route returns `401` JSON for guests — never a `302` redirect or a `RouteNotFoundException` for a missing `login` route (Task 3).

```php
<?php

namespace App\Domain\Authorization;

/**
 * Institution-mail policy — port of pre-laravel-final-state
 * `app/core/email_policy.py`. Subdomains of an allowed domain match;
 * lookalikes (`pdn.ac.lk.evil.com`) do not (dot boundary required).
 */
final class EmailPolicy
{
    public static function normalize(string $email): string
    {
        return strtolower(trim($email));
    }

    public static function domain(string $email): string
    {
        $parts = self::split($email);

        return $parts === null ? '' : $parts[1];
    }

    /**
     * @param  list<string>|null  $domains
     */
    public static function isInstitution(string $email, ?array $domains = null): bool
    {
        $allowed = array_map(
            static fn (string $domain): string => strtolower(ltrim(trim($domain), '@')),
            $domains ?? self::allowedDomains(),
        );

        $parts = self::split($email);

        if ($parts === null) {
            return false;
        }

        foreach ($allowed as $domain) {
            if ($parts[1] === $domain || str_ends_with($parts[1], '.'.$domain)) {
                return true;
            }
        }

        return false;
    }

    public static function error(): string
    {
        return 'Institution email required (allowed: '.implode(', ', self::allowedDomains()).')';
    }

    /**
     * @return list<string>
     */
    private static function allowedDomains(): array
    {
        $raw = (string) config('blitto.allowed_email_domains', 'pdn.ac.lk');

        return array_values(array_filter(
            array_map(
                static fn (string $domain): string => strtolower(ltrim(trim($domain), '@')),
                explode(',', $raw),
            ),
            static fn (string $domain): bool => $domain !== '',
        ));
    }

    /**
     * @return array{0: string, 1: string}|null
     */
    private static function split(string $email): ?array
    {
        $address = self::normalize($email);

        if (substr_count($address, '@') !== 1) {
            return null;
        }

        [$local, $domain] = explode('@', $address, 2);

        if ($local === '' || $domain === '' || preg_match('/\s/', $address) === 1) {
            return null;
        }

        return [$local, $domain];
    }
}
```

```php
<?php

namespace App\Http\Controllers\Auth;

use App\Domain\Authorization\EmailPolicy;
use App\Http\Controllers\Controller;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

final class LoginController extends Controller
{
    public function store(Request $request): JsonResponse
    {
        $email = EmailPolicy::normalize((string) $request->input('email', ''));
        $password = (string) $request->input('password', '');

        if (! EmailPolicy::isInstitution($email)) {
            return response()->json(['message' => 'Institution email required'], 403);
        }

        if (! Auth::attempt(['email' => $email, 'password' => $password])) {
            return response()->json(['message' => 'Invalid credentials'], 401);
        }

        $request->session()->regenerate();

        return response()->json(Auth::user(), 200);
    }
}
```

```php
<?php

namespace App\Domain\Authorization;

use App\Models\User;
use Illuminate\Database\Eloquent\Collection;
use Illuminate\Support\Facades\Hash;
use InvalidArgumentException;

/**
 * Single entry point for creating and looking up users. Normalizes email,
 * enforces the institution gate, rejects duplicates, and hashes passwords
 * (bcrypt refuses >72 bytes rather than truncating silently).
 */
final class UserDirectory
{
    public const int MAX_PASSWORD_BYTES = 72;

    public function register(string $email, Role $role, ?string $password = null, ?string $userCode = null): User
    {
        $email = EmailPolicy::normalize($email);

        if (! EmailPolicy::isInstitution($email)) {
            throw new InvalidInstitutionEmail(EmailPolicy::error());
        }

        if ($this->findByEmail($email) !== null) {
            throw new DuplicateEmail("email already registered: {$email}");
        }

        return User::query()->create([
            'email' => $email,
            'role' => $role->value,
            'user_code' => $userCode,
            'password_hash' => $password === null ? null : $this->hash($password),
        ]);
    }

    public function findByEmail(string $email): ?User
    {
        return User::query()->where('email', EmailPolicy::normalize($email))->first();
    }

    /**
     * @return Collection<int, User>
     */
    public function all(): Collection
    {
        return User::query()->orderBy('email')->get();
    }

    private function hash(string $password): string
    {
        if (strlen($password) > self::MAX_PASSWORD_BYTES) {
            throw new InvalidArgumentException('password exceeds 72 bytes (bcrypt limit)');
        }

        return Hash::make($password);
    }
}
```

```php
namespace App\Http\Middleware;

use App\Domain\Authorization\Role;
use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

/**
 * RBAC gate mirroring the endpoint RBAC matrix. Roles are the lowercase
 * `Role` enum values; guests get 401, absent roles get 403.
 */
final class EnsureRole
{
    public function handle(Request $request, Closure $next, string ...$roles): Response
    {
        $user = $request->user();

        if ($user === null) {
            return response()->json(['message' => 'Unauthenticated.'], 401);
        }

        $allowed = array_map(static fn (string $role): Role => Role::from($role), $roles);

        if (! in_array(Role::from($user->role), $allowed, true)) {
            return response()->json(['message' => 'Forbidden.'], 403);
        }

        return $next($request);
    }
}
```

```php
<?php

namespace App\Domain\Authorization;

use Illuminate\Support\Facades\RateLimiter;

/**
 * Sliding-window attempt limiter for credential endpoints, mirroring the
 * FastAPI-era guards (login per account, vault unlock per IP):
 * 5 failures within 10 minutes, cleared on success.
 */
final class AttemptThrottle
{
    public const string LOGIN = 'login';

    public const string VAULT_UNLOCK = 'vault-unlock';

    public const int MAX_ATTEMPTS = 5;

    public const int DECAY_SECONDS = 600;

    public function locked(string $scope, string $subject): bool
    {
        return RateLimiter::tooManyAttempts($this->key($scope, $subject), self::MAX_ATTEMPTS);
    }

    public function recordFailure(string $scope, string $subject): void
    {
        RateLimiter::hit($this->key($scope, $subject), self::DECAY_SECONDS);
    }

    public function clear(string $scope, string $subject): void
    {
        RateLimiter::clear($this->key($scope, $subject));
    }

    public function retryAfter(string $scope, string $subject): int
    {
        return RateLimiter::availableIn($this->key($scope, $subject));
    }

    private function key(string $scope, string $subject): string
    {
        return $scope.':'.strtolower($subject);
    }
}
```

```php
namespace App\Http\Controllers\Auth;

use App\Domain\Authorization\AttemptThrottle;
use App\Domain\Authorization\EmailPolicy;
use App\Http\Controllers\Controller;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;

final class LoginController extends Controller
{
    public function __construct(private readonly AttemptThrottle $throttle) {}

    public function store(Request $request): JsonResponse
    {
        $email = EmailPolicy::normalize((string) $request->input('email', ''));
        $password = (string) $request->input('password', '');

        if (! EmailPolicy::isInstitution($email)) {
            return response()->json(['message' => 'Institution email required'], 403);
        }

        if ($this->throttle->locked(AttemptThrottle::LOGIN, $email)) {
            return response()->json(['message' => 'Too many login attempts'], 429)
                ->header('Retry-After', '600');
        }

        if (! Auth::attempt(['email' => $email, 'password' => $password])) {
            $this->throttle->recordFailure(AttemptThrottle::LOGIN, $email);

            return response()->json(['message' => 'Invalid credentials'], 401);
        }

        $this->throttle->clear(AttemptThrottle::LOGIN, $email);
        $request->session()->regenerate();

        return response()->json(Auth::user(), 200);
    }
```

```php
<?php

namespace App\Domain\Authorization;

use InvalidArgumentException;

/**
 * Creates the first MD from BLITTODB_BOOTSTRAP_ADMIN_* so the system is usable
 * out of the box. Idempotent; refuses institution-foreign mail and, outside
 * local, placeholder passwords (parity with the FastAPI startup bootstrap).
 */
final class BootstrapAdmin
{
    private const array PLACEHOLDER_PASSWORDS = [
        'password',
        'changeme',
        'change-me-in-production-32byte-minimum!',
    ];

    public function __construct(private readonly UserDirectory $directory) {}

    public function ensure(): void
    {
        $email = (string) config('blitto.bootstrap_admin_email', '');
        $password = (string) config('blitto.bootstrap_admin_password', '');

        if ($email === '' || $password === '') {
            return;
        }

        if (strtolower((string) config('blitto.environment', 'local')) !== 'local'
            && in_array($password, self::PLACEHOLDER_PASSWORDS, true)) {
            throw new InvalidArgumentException('Bootstrap admin password must not be a placeholder outside local.');
        }

        if ($this->directory->findByEmail($email) !== null) {
            return;
        }

        $this->directory->register($email, Role::MD, $password);
    }
}
```

```php
<?php

namespace App\Http\Controllers;

use App\Domain\Lifecycle\ApplicationStatus;
use App\Domain\Lifecycle\LifecycleService;
use App\Models\Application;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;

/**
 * Thin controller: parses input, delegates to LifecycleService, returns 204.
 * Domain rules (transition table) live in App\Domain\Lifecycle.
 */
class ApplicationStatusController extends Controller
{
    public function __construct(private readonly LifecycleService $lifecycle) {}

    public function store(Request $request, Application $application): JsonResponse
    {
        $validated = $request->validate([
            'new_status' => ['required', 'string'],
            'reason' => ['required', 'string', 'min:1'],
        ]);

        $this->lifecycle->changeStatus(
            $application,
            ApplicationStatus::from($validated['new_status']),
            changedBy: (string) $request->user()->email,
            reason: $validated['reason'],
        );

        return response()->json(null, 204);
    }
}
```
